# theme-assets

CDN assets for Nuvemshop themes. Served via [jsDelivr](https://www.jsdelivr.com/).

## Usage

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/uncodelabs/theme-assets@main/css/admin-css-advanced.css" />
```

## Structure

```
css/
  admin-css-advanced.css   # Generated from Figma contracts
```

## Cache

jsDelivr caches for ~24h. To purge:

```
https://purge.jsdelivr.net/gh/uncodelabs/theme-assets@main/css/admin-css-advanced.css
```
